# src_ml de la tanda v2

No ejecutar desde aquí. El `paths.py` vivo asume
`online_policy_ml/src_ml/`; una copia en esta carpeta resolvería
`ML_ROOT` a `versions/v2` y anidaría mal modelos y reports.

Tras un run de `05` que se quiera sellar, copiar aquí los `.py` del
árbol vivo (`train_ppo.py`, `paths.py`, `config.py`, `evaluate.py`).
