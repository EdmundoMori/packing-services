\paragraph{Interrupted attempts and recovery.}
Attempt~01 wrote \codepath{learning_labels/}; attempt~02 wrote
\codepath{learning_labels_recovery/}. Both stopped with unknown exit code/cause
while \codepath{progress.status=running}. Demonstrated facts include non-atomic
writes in the attempt~01 executor, empty files under \texttt{00108806}, and
progress/content inconsistency; the corruption mechanism is not established.
Attempt~02 referenced twelve verified orders via read-only links, counted sixteen
preflight continuations once, and left development unfinished. Forty-six
content-verified orders from attempts~01/--02 were reusable
($12$ referenced $+33$ new $+1$ inevitable repeat); twenty-six were pending
($2$ train $+24$ development). Staging directories were not auto-promoted.

\paragraph{Training and development episodes.}

after an abort that never left hash validation (\texttt{2176460}). Models were
published in \texttt{2b4f5e9}. The first authorised development episode campaign
wrote $240$ keys but every worker crashed before capture when
\codepath{Path.resolve()} followed the venv interpreter symlink to the system
Python (no \texttt{torch}). That run remains archived under
\codepath{learning_development_eval/} as operational evidence only.
After the absolute-venv fix, a hash-compatible smoke reuse plus $232$ new
episodes completed the $240$-key development evaluation under
\codepath{learning_development_eval_full/}. The frozen gate did not pass
(preferences below classification on the primary contrast; both arms behind
Greedy). Test packing remains closed. Seventeen untracked historical transition pickles remain
excluded from versioned scientific claims.
