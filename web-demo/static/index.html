Portal de servicios de Cutting & Packing

Descubre algoritmos, ejecuta uno con entrada BED-BPP y compara motores con el mismo validador y las mismas métricas. Dos modos: offline (pedido completo) y online (llegada en secuencia, incluida la política aprendida).

1 · Catálogo

Tipo de problema → tarjetas de modelo → detalle completo.

2 · Ejecutar

Tipo de problema → algoritmo → pedido BED-BPP + parámetros.

3 · Benchmark

Tipo de problema → motores → dataset BED-BPP (batch) + pedido.

Arquitectura del demo

Un único servidor expone esta interfaz web (puerto 8080) y hace proxy a la API packing-services (puerto 8000). El núcleo del proyecto no se modifica: la UI consume los endpoints existentes /api/v1/algorithms, /api/v1/algorithms/{name}/execute y /api/v1/benchmark.
