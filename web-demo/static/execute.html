Ejecutar un algoritmo

Elige un pedido BED-BPP → el JSON muestra solo esa instancia (lo que recibe el algoritmo) → configura parámetros → ejecuta. El modo (offline u online) usa el mismo dataset. En online, drl_policy_3d_bpp usa la política RL (PPO), un empate estadístico con el heurístico.

Política aprendida: RL (PPO) — mlp_v1_p1s1_ppo.pt. Empate estadístico con el heurístico online. Con dos o más pallets el execute aplica disciplina first-fit (consolidate, default activo). consolidate=false restaura el reparto libre. Si basta el motor simple, usa online_3d_bpp_heuristic.
